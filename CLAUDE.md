# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

Personal collection of AI prompts organized by category for general use, persona emulation, pair programming, and model evaluation.

## Structure

- **Custom-Preferences/** - System instructions for different AI platforms (Claude, Gemini, Grok)
- **Evals/** - Evaluation prompts for testing AI capabilities
- **Learning/** - Iterative learning prompt templates
- **Notes/** - Reference notes and tips
- **Pair-Programming/** - Prompts for coding assistance workflows
- **Personas/** - Persona-based prompts (Feynman, Munger, etc.)
- **Reviewers/** - Prompts for writing critique and research navigation

## Conventions

- Prompts are stored as `.md` or `.txt` files
- Version suffixes (e.g., `-v0`, `-v1`, `-v2`) indicate prompt iterations
- No build, lint, or test commands - this is a content-only repository
